# GraveTurn

A dark pixel-art turn-based combat game made in Java using Swing.

## About the game

GraveTurn is a small tactical combat game where the player faces a single enemy in a series of rounds. Every decision matters: attack, dodge, or heal.

The goal is simple: survive the enemy attacks, reduce their health, and win the battle before you fall.

## Features

- Turn-based combat
- Attack, dodge and healing mechanics
- Pixel-art style visuals
- Save system for progression and settings
- Main menu, settings panel and end screen
- Tutorial explaining combat rules
- Sound effects and background music

## Controls

- Click the action buttons during your turn
- Use the sword to attack
- Use the dodge icon to attempt a dodge/parry
- Use the potion to heal

## Combat rules

- If the dodge succeeds, the attack is completely avoided
- If the dodge fails, only half the damage is taken
- If the enemy dodges your attack, your attack is completely avoided
